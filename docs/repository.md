# 仓库结构与复现边界

本目录是独立的 `CrossInterest` 研究仓库，不嵌套在MIND项目内，也不包含私有研究归档。源码在 `src/crossinterest`，配置在 `configs`，测试在 `tests`，实验论证和结果在 `docs/experiments`；原始数据与生成产物不随Git发布。研究入口对齐PPT的任务、数据、表示、基线和CIR主线，后期结构研究单独解释。

## 公开接口

[RESULTS.md](../RESULTS.md)位于仓库根目录，是正式实验结果的唯一集中入口；分支报告保留方法、预算与审计说明，不再保留另一份总结果文档。

[英文README](../README.md)给出安装、只读检查、单阶段训练与完整词表排序命令。研究模块按问题命名，例如 `methods/cir`、`methods/factorization`、`methods/role_projection` 和 `methods/mass_readout`；同一方法的模型、数据、训练和审计不再散落在一个巨型目录。99类旧协议在 `legacy` 中明确隔离。

`data`只负责本地数据，`outputs`只负责运行产物。公开YAML不携带Azure订阅、工作区、存储账户或个人路径。默认CLI不会创建云端作业；使用者自行选择计算平台。

本目录不保留另一份公开源码、发布包解压副本、验证用克隆或旧目录链接。`__init__.py`是必要的Python包边界，不是重复实现；不同实验协议也不能仅因文件名相似就合并。仓库检查器拒绝非空公开文件的完全重复内容，缓存、安装元数据和运行产物不作为源码分发。

## 本地历史来源

原工作区、迁移映射及环境留在仓库之外的私有研究资料目录，不复制到本目录。冻结提交内部文件没有改写，218份合同、预检清单和受保护设计内容SHA保持不变。原文件位置变化不等于权重或训练协议变化。

公开源文件经过模块与导入重组，因此新源码SHA不应拿来冒充旧作业的合同SHA。需要严格复现旧云端提交时，应使用私有归档中的原冻结包；需要继续开发时，应使用公开包及新的配置，而不是原地修改归档。

部分历史编排、监控和收集接口依赖原合同及产物，只供有归档的研究者核查，不是公开quick start。`CROSSINTEREST_LEGACY_WORKSPACE`可用于显式定位本地历史来源；未提供来源时，不应宣称能恢复任何旧作业。

## 验证范围

轻量测试不依赖数据或模型下载。真实tiny-model回归需安装训练依赖；全量历史测试还需本地产物。迁移没有启动9B训练，也不承诺新布局与旧四卡运行逐位一致。

仓库所有权、开源许可证与第三方实现再分发许可仍需维护者确认，技术检查通过不能替代法律授权。正式实验与负结果参见[实验总览](experiments/overview.md)。
