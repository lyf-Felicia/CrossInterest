# CIR：已有兴趣识别辅助预热

> 交接整理：2026-10-08。CIR 是新兴趣预测的预热任务，不取代最终 N 任务。

## 研究问题与设置

根据行为历史识别用户已有兴趣，随后迁移到下一新兴趣预测。该任务不同于最初的类别名称与ID字典对齐：它提供历史级监督。目录包含基础和语义输入版本、外部平衡数据以及恢复记录；正式预算与来源必须取对应运行合同，不能套用后续 G0 的预算到所有早期版本。

## 结果与解释边界

| 正式条件 | Recall@10 ↑ | Recall@20 ↑ | nDCG@10 ↑ | nDCG@20 ↑ |
|---|---:|---:|---:|---:|
| Qwen，balanced CIR | 0.235994 | 0.377801 | 0.121613 | 0.157133 |
| Llama，balanced CIR | 0.232901 | 0.380894 | 0.121194 | 0.158506 |
| Llama，original CIR | 0.240225 | 0.380369 | 0.119453 | 0.154541 |
| Qwen，semantic true | 0.221843 | 0.368785 | 0.114764 | 0.151856 |
| Qwen，semantic shuffled | 0.238416 | 0.378356 | 0.121855 | 0.156795 |

表内均为各条件完整Dev2000/112类，来自下列基础与语义两份审计。真实语义条件并未超过shuffled条件，因此不能把效果归因于语义正确性；不同数据版本与模型也不构成单变量对照。

基础与语义分支均留有原始结果审计及最终完成记录。该目录是后续方向性、因子分解与冻结CIR研究的来源之一；引用任何“CIR收益”时，应明确输入语义、预热样本、N初始化和匹配对照，而不是把所有后续结果统称为同一个CIR方法。
