# CIR 信息因子分解

> 交接整理：2026-10-08。将CIR收益拆成可检验的对照，而不是仅比较“有/无预热”。

## 研究问题与设置

G0为来源经过审计的参考条件，G1至G4为因子控制。CIR损失拆成未见集合内的关系项和已见排除项，分别调整二者相对权重，并匹配首ID梯度幅度；真实与伪seen mask作为配对控制。伪mask保持行列边际，不代表均匀随机采样。各G编号与具体损失臂的对应以冻结运行合同为准。该目录保留门禁、速度验证、正式提交和中断恢复，不把门禁或速度smoke的结果纳入正式效果表。
