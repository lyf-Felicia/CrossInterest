# 骨干模型与规模对照

> 交接整理：2026-10-08。本实验回答基础模型选择是否比辅助任务改动更重要。

## 研究问题与设置

在 Amazon Home 的 B+I 输入和语义 Interest ID 输出下，对比不同骨干及规模。先核对单阶段与两阶段预算，不能把更大模型、更多训练步骤和任务变化混成一个因素。追加 Qwen3.5-27B 为单阶段 112K / 3,500 步，完整 Dev2000。

## 结果与解释

27B 的 Recall@10/20、nDCG@10/20 分别为 0.2219 / 0.3734 / 0.1188 / 0.1572，已完成原始排名与 adapter 验收；相对本轮 9B 并非四项均提升。历史八骨干与追加规模结果的分组仍保留在原研究设计汇总中，本次不改写该受保护文档，也不把不同运行的 9B 对照互换。
