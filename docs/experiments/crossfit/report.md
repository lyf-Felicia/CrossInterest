# Cross-fitted 评分与类内加权

> 交接整理：2026-10-08。这是历史数据加权探索，不是当前结构改进协议的一部分。

## 研究问题与设置

用五折教师对完整112K训练数据产生样本外评分，再生成类内权重并训练学生，考察难度或可靠性加权是否改善预测。教师评分、权重和学生结果分开保存；不得把训练内评分当作样本外评分，也不能将这一分支的加权监督悄悄带入禁止改数据的新结构实验。

## 结果与解释

学生的 Recall@10/20、nDCG@10/20 为 0.2305 / 0.3689 / 0.1186 / 0.1535，完成正式训练及原始排名验收。相对本轮无权重9B四项正向，但 Recall@20 基本持平；单seed开发集结果不足以支持显著收益。
