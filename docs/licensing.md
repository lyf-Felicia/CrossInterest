# Licensing and Third-Party Sources

The repository owner has not selected a project license. No license grant or copyright ownership is inferred from a directory reorganization. Confirm ownership of the original contributions and add the chosen license before publicly redistributing the repository as open source.

The project adapts or references external research methods. Project documentation distinguishes the MeRA reproduction from the MiniOneRec-inspired auxiliary tasks; neither reference grants permission to relicense third-party code.

- Amazon Reviews 2023 data: obtain data from the original distribution and comply with its terms. Reviews and user data are excluded from the repository.
- MIND data: historical, separately obtained and excluded from Git.
- Qwen and Llama checkpoints: download from their original model repositories, check access requirements, and retain the applicable model terms.
- MeRA and MiniOneRec: retain method attribution in the relevant experiment reports. Official snapshots in the private archive are not distributed by this repository.
- PyTorch, Transformers, PEFT, and other dependencies: retain their own licenses; installing a dependency does not transfer its license to this project.

Before publication, the maintainer must review adapted code, citations, code ownership, and any required notices. Do not add a permissive license to code whose redistribution rights have not been established.
